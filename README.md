# great-wall-ux

**The Wall's appearance.** Rendering, palettes, interaction and effects — separated from the engine so visual work never touches `great-wall-core`.

Part of [Great Wall](https://github.com/Yuri-SVB/Great-Wallet), which pins
this library to a compatible commit. This repository has no submodules.

**Status:** In development.

**Documentation:** [great-wall-docs/great-wall-ux](https://github.com/Yuri-SVB/great-wall-docs/tree/main/great-wall-ux)
— design, architecture and threat model live there, not here.

## Build

```sh
flutter pub get
```
